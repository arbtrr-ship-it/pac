# Где разместить PAC: сравнение хостингов простыми словами

> Документ для продуктовой команды. Без кода и технического жаргона.
> Все выводы опираются на официальные источники — ссылки в конце.

---

## Коротко: что важно понять про приложение

PAC — это **статический сайт**. Браузер скачивает готовые файлы и всё считает
прямо на устройстве пользователя. **Сервера нет, базы данных нет, сборки нет.**

```
  ┌─────────────┐        отдаёт готовые файлы       ┌──────────────────┐
  │   Хостинг   │  ───────────────────────────────► │ Браузер человека │
  │ (любой из   │   index.html, styles.css, js/*.js │  ▸ здесь считается│
  │  сравнения) │                                   │    ВСЯ логика:    │
  └─────────────┘   ◄── никаких запросов обратно ──  │    скоринг, PAS,  │
        ▲                (нет сервера, нет API)      │    роадмап, AI    │
        │ деплой из GitHub                           └──────────────────┘
  ┌─────┴──────┐
  │   GitHub   │  ← здесь лежит исходник (единственный «источник правды»)
  └────────────┘
```

Из этого следует три вещи, которые снимают большинство вопросов:

1. **Переезд не ломает функции.** Скоринг, роадмап, AI Office, стратегия — всё
   работает в браузере и не зависит от площадки. Единственный «хвост» под
   конкретный хостинг — файл `_redirects` (формат Netlify). На Cloudflare Pages
   он работает как есть; на Timeweb те же 2 правила переписываются в настройках.
2. **Базы данных сейчас не нужно нигде.** Данные живут в памяти вкладки и
   стираются при перезагрузке — так задумано на этапе демо.
3. **Резервные копии данных не требуются** — терять нечего, потому что база
   отсутствует. Восстановление = заново развернуть из GitHub.

## Сравнение площадок

| | **Cloudflare Pages** 🥇 | **Timeweb (РФ)** 🥈 | Vercel | Netlify (сейчас) | Railway |
|---|---|---|---|---|---|
| Тип | статика | статика / хостинг | статика | статика | серверы/приложения |
| Функции сохранятся | ✅ да | ✅ да | ✅ да | ✅ да | ✅ да, но избыточно |
| Цена малого старта | **0 ₽** | ~99–393 ₽/мес | $0, платный $20/мес | $0 (беспл. тариф) | от $5/мес |
| Оплата из РФ | **не нужна** | **МИР, СБП, ЮMoney** | ❌ карта РФ не проходит | ❌ на платном не проходит | ❌ нужна зарубежная карта |
| Лимит трафика | **безлимит** | по тарифу | 100 ГБ/мес | 100 ГБ/мес | по потреблению |
| Где серверы/данные | мировая сеть | **есть ЦОД в РФ** | вне РФ | вне РФ | вне РФ |

**Главная развилка — оплата.** Vercel, Netlify и Railway принимают деньги через
Stripe, а он не обслуживает российские карты. Пока вы на бесплатном тарифе —
всё работает; но как только упрётесь в лимит или понадобится коммерческий тариф,
заплатить будет нечем. Railway вдобавок технически лишний: он создан для
приложений с сервером и базой, которых у вас нет.

## Ответы на пять вопросов

### 1. Сохранится ли работа без переделки функций?
**Да, на любой из площадок.** Вся логика — в браузере. При переезде меняется
только способ отдачи файлов и правила переадресации (`_redirects`). На Cloudflare
Pages это буквально тот же файл; на Timeweb — пара строк в настройках.

### 2. Какие доп. сервисы понадобятся и зачем?
Для самого приложения — **никаких.** Уже настроено и стоит сохранить:
- **Автомонитор доступности** (GitHub Actions, файл `.github/workflows/uptime-monitor.yml`)
  — раз в день проверяет, что сайт жив, и шлёт тревогу в **Telegram**.
- **GitHub** — хранит исходник и запускает деплой.

База данных и бэкенд понадобятся **только** если вы захотите логин и сохранение
данных (см. блок «Если появится сохранение данных»).

### 3. Где будут храниться данные пользователей?
**Сейчас — нигде постоянно.** Данные живут в памяти вкладки и **исчезают при
перезагрузке** (задумано для демо). Ничего не уходит на сервер, персональные
данные не собираются и не хранятся.

### 4. Сколько стоит малый запуск и чем платить?
- **Cloudflare Pages — 0 ₽, карта не нужна вообще.** Безлимитный трафик.
- **Timeweb — от ~99 ₽/мес** (фронтенд-приложение из GitHub) или от ~180–393 ₽/мес
  (классический хостинг). Оплата **картой МИР, через СБП или ЮMoney** в рублях.
- Vercel/Netlify бесплатны на старте, но при переходе на платный тариф российской
  картой **оплатить нельзя**.

### 5. Как заметить сбой и восстановить работу?

```
  [ Автомонитор раз в день ] ──проверяет──► сайт открывается? файлы на месте?
            │
            ├─ всё хорошо ─► молчит
            │
            └─ поломка ────► 🔴 сообщение в Telegram
                                   │
                                   ▼
                         Восстановление (минуты):
                         1) откатиться на прошлый деплой
                            в истории версий площадки, ИЛИ
                         2) заново развернуть из GitHub.
                         Данные не теряются — базы нет.
```

## Рекомендация: основной + запасной

**🥇 Основной — Cloudflare Pages.** Бесплатно, карта не нужна, безлимитный трафик,
деплой из GitHub, файл `_redirects` работает без изменений. Все функции
сохраняются. Лучший баланс цены и риска для вашего масштаба.

**🥈 Запасной — Timeweb Cloud.** Российский провайдер, оплата рублёвой картой,
дата-центры в РФ, поддержка на русском. Берём, если нужен провайдер в РФ или
рублёвая оплата — особенно когда появится логин и требование хранить данные в РФ.

Оба варианта сохраняют **все** функции проекта — поэтому и отобраны.

## Если в будущем появится сохранение данных (логин)

Тогда картина меняется: понадобится **сервер + база данных**, и появится вопрос,
**где физически лежат данные пользователей**.

```
  Сегодня:                        Если добавить логин:
  ┌─────────┐                     ┌─────────┐   ┌────────┐   ┌──────────┐
  │ Браузер │  (данные в памяти)  │ Браузер │──►│ Сервер │──►│   База   │
  └─────────┘                     └─────────┘   └────────┘   │  данных  │
                                                             └──────────┘
```

В этом сценарии **Timeweb выходит вперёд**: у него есть и серверы, и базы данных,
и дата-центры в РФ, и рублёвая оплата. Cloudflare Pages сам по себе — только для
статики. Это стоит держать в голове при выборе, чтобы не переезжать дважды.
